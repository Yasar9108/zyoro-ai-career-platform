# 🤖 Zyoro AI

### AI-Powered Career Platform

Zyoro AI is an AI-powered career platform designed to help candidates
build better resumes, evaluate ATS readiness, prepare for realistic
technical interviews, practice coding, and discover relevant job
opportunities.

Zyoro AI is being developed as a complete AI-powered career ecosystem
combining Resume Intelligence, AI Interview Preparation, Live Coding,
Job Hunting, and Career Assistance.

# 1. 💻 AI Live Coding Interview

### Status: 🚧 In Progress

The AI will act as a technical interviewer rather than simply
providing a coding editor.

## Planned Interview Flow

```text
AI presents coding problem
        ↓
Candidate explains approach
        ↓
AI evaluates reasoning
        ↓
AI approves approach
        ↓
Code editor unlocks
        ↓
Candidate writes code
        ↓
Run code / test cases
        ↓
AI asks technical follow-up questions
        ↓
AI evaluates solution
        ↓
Coding Interview Report
